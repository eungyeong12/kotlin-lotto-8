# 로또

## 기능 목록

### 1. 로또 구입 금액을 입력 받는다.

- 1,000원 이상이 아니라면, "[ERROR] 로또 금액은 1,000원 이상이어야 합니다."라는 에러 메시지를 보여 준다.
- 1,000원 단위가 아니라면, "[ERROR] 로또 금액은 1,000원 단위여야 합니다."라는 에러 메시지를 보여 준다.

### 2. 구입 금액에 해당하는 만큼 로또를 발행하고 발행한 로또 수량 및 번호를 출력한다.

- 로또 번호는 오름차순으로 정렬하여 보여준다.

### 3. 당첨 번호를 입력 받는다. 

- 쉼표 기준으로 구분한다.
- 각 숫자가 1에서 45 사이가 아니라면, "[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다."라는 에러 메시지를 보여 준다.
- 번호가 중복된다면, "[ERROR] 로또 번호는 중복되지 않아야 합니다."라는 에러 메시지를 보여 준다.
- 번호가 6개가 아니라면, "[ERROR] 로또 번호는 6개여야 합니다."라는 에러 메시지를 보여 준다.

### 4. 보너스 번호를 입력 받는다.

- 1에서 45 사이의 숫자가 아니라면, "[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다."라는 에러 메시지를 보여 준다.
- 번호가 당첨 번호와 중복된다면, "[ERROR] 로또 번호는 당첨 번호와 중복되지 않아야 합니다."라는 에러 메시지를 보여 준다.

### 5. 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 구한다.

### 6. 당첨 내역 및 수익률을 출력한다.
