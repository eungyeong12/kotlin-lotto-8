# 로또

## 기능 목록

### 1. 로또 구입 금액을 입력 받는다.

- 구입 금액은 1,000원 단위이다.
- 구입 금액이 비어 있을 경우, '구입 금액을 입력해 주세요.' 메시지를 던진다.
- 구입 금액이 정수가 아닐 경우, '구입 금액은 정수여야 합니다.' 메시지를 던진다.
- 구입 금액이 1,000원 이상이 아닐 경우, '구입 금액은 1,000원 이상이어야 합니다.' 메시지를 던진다.
- 구입 금액이 1,000원 단위가 아닐 경우, '구입 금액은 1,000원 단위여야 합니다.' 메시지를 던진다.

### 2. 구매 수량만큼 로또를 발행한다.

- Lottos 클래스에서 Lotto 리스트를 관리한다.
- Lotto에서 로또 번호를 관리한다.
- 정수 리스트를 반환하는 함수를 가진 NumbersProvider 인터페이스가 필요하다.
- RandomNumbersProvider는 6개의 원소를 가진 정수 리스트를 오름차순으로 정렬하여 반환하는 함수를 가진다.

### 3. 발행한 로또 수량 및 번호를 출력한다.

### 4. 당첨 번호를 입력 받는다.

- 번호는 쉼표를 기준으로 구분한다. 
- 당첨 번호가 비어 있을 경우, '당첨 번호를 입력해 주세요.' 메시지를 던진다.
- 정수가 아닌 번호가 있을 경우, '정수가 아닌 번호가 있습니다.' 메시지를 던진다.
- 번호가 1~45의 범위가 아닌 경우, '당첨 번호는 1에서 45 사이여야 합니다.' 메시지를 던진다.
- 당첨 번호가 6개가 아니라면, '당첨 번호는 6개여야 합니다.' 메시지를 던진다.
- 중복되는 번호가 있을 경우, '당첨 번호는 중복되지 않아야 합니다.' 메시지를 던진다.

### 5. 보너스 번호를 입력 받는다.

- 보너스 번호는 당첨 번호와 중복되지 않아야 한다.
- 보너스 번호가 비어 있을 경우, '보너스 번호를 입력해 주세요.' 메시지를 던진다.
- 보너스 번호가 정수가 아닐 경우, '보너스 번호는 정수여야 합니다.' 메시지를 던진다.
- 번호가 1~45의 범위가 아닌 경우, '보너스 번호는 1에서 45 사이여야 합니다.' 메시지를 던진다.
- 보너스 번호가 당첨 번호와 중복되는 경우, '보너스 번호는 당첨 번호와 중복되지 않아야 합니다.' 메시지를 던진다.
